# 高清重制与 TTS 重构

`release` 分支从旧版基线 Tag `v0.1.5` 开始，目标是在保留完整主线和经典像素基准的前提下，逐步建设高清展示与离线角色语音。重构阶段不得把尚未验收的新路径反向混入旧版 Tag。

## 不变边界

- 正式地图运行继续以 `TileMapLayer + PalTileMapWorld` 为唯一实现；CPU 合成只用于测试对照。
- 原版地图、RNG、FBP、战斗坐标和脚本语义继续使用 `320×200` 经典内容空间。
- 高清模式改变最终展示画布、高清 UI 和可替换素材，不复制人物选帧、坐标换算、调色板、Y 排序或遮挡规则。
- TTS 只使用离线生成的本地音频；客户端不包含 MiniMax Key，也不调用在线生成接口。
- `Data/`、`generated/`、TTS 音频和包含原版派生内容的移动验收包仍保持 Git 忽略。

## 高清展示结构

`PalPresentationMetrics` 统一定义经典内容尺寸、默认四倍高清画布和整数缩放后的居中区域。后续高清画面按以下层次推进：

1. 经典内容层保持 `320×200`，继续承担地图、人物、剧情动画和像素回归。
2. 展示壳使用更大的输出 Viewport，把经典内容按整数倍居中，不产生插值模糊。
3. 高清 UI、字幕、语音状态和宽屏装饰放在输出画布层，不改变经典世界坐标。
4. 高清人物、地图和特效通过共享资源解析层逐项替换；缺少高清资源时安全回退到经典素材。
5. 每个替换阶段都用正式 TileMap 窗口截图验收，并继续保留 320×200 零差异回归。

## TTS 数据与运行时

MiniMax 只参与开发期离线资产生成：

1. `ScriptVM.dialog_round_ready` 在一整轮正文收齐时发出稳定的消息 ID 序列；说话人标题不进入朗读文本，分页保持独立轮次。
2. 本地生成清单保存正文消息 ID、说话人、音色、语速、文本哈希和输出文件；源文本变化后必须重新生成对应语音。
3. 运行时语音目录按消息 ID 序列查找音频，不从显示文字反推文件名。
4. 独立 `AudioStreamPlayer` 播放角色语音；对白推进、跳过和场景切换必须停止旧语音，不能占用 BGM 或八路原版音效池。
5. 系统菜单最终提供独立语音开关／音量。缺少语音文件时对白照常运行，不显示资源导入错误。
6. 第一章先完成角色选角、全对白生成、实际听检与游戏内回归，再扩展到后续章节。

## 发布约束

桌面公开包继续采用“玩家本地导入合法取得的 Data”模式。当前 Android 本地验收包会内置原版派生资源；只有在明确具备相应分发授权时，才能把这类 APK 上传为公开 Release 附件。
