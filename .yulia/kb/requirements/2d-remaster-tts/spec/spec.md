# 规格说明：精致国风像素 2D 高清重制与第一章 TTS

**需求 ID**: `2d-remaster-tts`
**目标分支**: `release`
**目标平台**: PC 桌面，1920×1080、16:9、60 FPS

## 产品目标

完整保留十八章剧情、事件脚本、地图拓扑、战斗、菜单、存档和玩家本地导入数据。正式画面不再使用 3D；地图、人物、立绘、战斗和特效全部重制为精致国风像素 2D。逻辑坐标、图块编号、人物锚点、遮挡、阻挡和交互语义不得改变。

项目保持免费、无广告、无赞助、非官方同人定位。公开代码仓不得包含原版提取资源、完整对白、私有高清素材、生成语音或凭据；实际图片和 TTS 保存到嵌套 Private 仓库 `sword-assets/`。

## 功能需求

### R1 1080p 2D 地图与坐标

- `TileMapLayer + PalTileMapWorld` 继续承担正式地图载入、选帧、Y 排序和遮挡；CPU 合成仅用于经典基准。
- 经典逻辑基准保持 320×200；高清逻辑视野为 384×216，并以 5 倍整数比例输出 1920×1080。
- 相机中心仍是 `session.viewport_position + (160,100)`；`PARTY_OFFSET=(160,112)`、事件坐标、脚本运镜和存档字段不变。
- 经典 UI 核心区位于高清逻辑画布 `(32,8,320,200)`，即物理区域 `(160,40,1600,1000)`；不得拉伸。
- 高清图块、人物纹理按 5 倍物理像素制作，在 PAL 逻辑世界按 0.2 比例放置，使 Camera2D 放大后保持 1:1 物理像素。

### R2 高清资源与回退

- 地图资源 ID 为 `map/{id}/tileset`；人物、立绘、战场、战斗动作、过场、语音和 UI 使用既有逻辑命名空间。
- 地图高清图块单元为 160×80，有效内容为 160×75；原 GOP 帧编号、上下层、高度和阻挡数据保持权威。
- 一张高清 TileSet 必须覆盖该地图实际引用的全部 GOP 帧；不完整或无效时整张地图回退经典图块 5 倍最近邻显示。
- 高清人物图集必须逐项映射原 MGO `frame_index`，同一人物共用画布和脚底原点；不得建立第二套动作状态机。
- 资源优先级为启用的 MOD → Private 高清包 → 玩家经典资源 → 合成占位资源。正式模式只接受 `approved` 条目。
- v1 MOD 只允许替换人物、立绘、语音和 UI，不执行脚本或修改地图逻辑。

### R3 2DCS + Bitto 人物生产

- `2D-Character-Starter` 规定角色画风迁移、姿势输入顺序、绿幕背景和输出命名；Bitto 是唯一图片生成后端。
- `nano-banana-2` 必须显式使用 `vertex` 协议生成快速草案；`gpt-image-2` 必须显式使用 `openai-images` 协议生成身份敏感定稿。不得静默换模型。
- 角色母版使用 2DCS `ct`：图 1 为原版角色基准板，图 2 为批准的目标像素画风。
- 四方向与动作候选使用 2DCS `p`：图 1 为批准母版，后续图片只提供骨架、方向、重心和落脚点。`sq` 只用于动作探索。
- 图片生成统一请求 1536×1024、3:2、纯绿幕、单角色；Sprite Video Lab 负责抠图，XSXB Frame Tuner Lite 负责统一画布、原点和时长。
- 每次输出保存 2DCS 模式、Bitto 模型/协议、输入顺序和哈希、提示词版本、请求/实际尺寸、输出 SHA-256 与审核状态。

### R4 第一章 TTS

- 运行时严格使用 `ScriptVM.dialog_round_ready(PackedInt32Array)` 的完整消息 ID 序列查找语音。
- MiniMax 只在开发期离线生成；客户端不得包含 Key 或调用在线 TTS。
- 当前只制作第一章剧情对白和旁白，不朗读菜单、物品获得、系统提示或战斗数值。
- 默认手动推进；真正翻页、跳过、切场景、进战斗和读档时停止旧语音。自动模式只在文字完整且语音自然结束后推进。
- 第一章先生成李逍遥、李大娘、旁白/NPC 三条样音；未人工批准前不得批量生成。

### R5 逐章交付

- 第一章先完成 Map 012 客栈、余杭/十里坡和梦境战斗垂直切片，锁定地图像素密度、人物比例、UI 与语音。
- 第二至十八章继续按原剧情章节边界完成视觉资源；当前不生成后续章节 TTS。
- 第十三章桃源村支线必须作为独立门禁完成真实运行验证。

## 验收与发布边界

- 223 张地图的 MAP/GOP 编号、阻挡、入口、事件和拓扑不得变化；经典 320×200 TileMap 基准继续保持零差异。
- Map 012 必须在真实 Godot 窗口生成 1920×1080 截图，核对连续木地板、两组低书架、床、挂画、盆栽柜、正确低凳、棋盘/火盆和贴墙书案。
- 角色必须通过正背左右身份、服装、武器、脚底稳定、轮廓闪烁、绿边和 Alpha 噪点检查。
- `.env.local` 必须被忽略且权限为 600；公开仓、日志和导出包不得出现 Bitto/MiniMax 凭据或 Private 内容。
- `v0.1.5` 保留为旧版基线；含原版派生资源的 APK 不上传公开 Release。公开分发前仍需完成权利与素材来源检查。
