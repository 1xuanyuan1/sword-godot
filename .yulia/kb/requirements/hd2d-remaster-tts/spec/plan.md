# 实施方案：非商业同人 HD-2D 高清重构与 TTS

**需求 ID**: `hd2d-remaster-tts` | **日期**: 2026-07-27 | **规格说明**: [spec.md](spec.md)

## 概要

在 `release` 分支分阶段实施。现有 `GameSession`、`ScriptVM`、`PalTileMapWorld`、经典战斗和存档保持权威；新增 3D 表现快照、高清资源解析、MOD、TTS 播放与 1080p 展示层。美术由 Bitto 生成概念与定稿素材，MiniMax 生成离线 Ogg。第一章垂直切片通过人工验收后，才按章节继续生产。

## 技术上下文

**语言/版本**: GDScript，Godot 4.7  
**主要依赖**: Godot Forward+、TileMapLayer、Sprite3D、MiniMax `speech-2.8-hd`、Bitto CLI、Git LFS、ffmpeg；可选 Tripo Studio 网页导出 GLB  
**存储方案**: 公开代码 Git 仓 + 嵌套 Private `sword-assets/` LFS 仓 + `user://mods/`  
**测试框架**: Godot SceneTree 合成测试、真实资源主线测试、带窗口视觉截图  
**目标平台**: PC/Windows 优先，macOS 开发验证  
**项目类型**: 单机桌面 RPG  
**性能目标**: 1920×1080、60 FPS，普通帧 p95 ≤ 16.7ms  
**约束条件**: 离线运行；无 Key 入包；TileMap 正式路径不可退化；经典存档与剧情语义兼容  
**规模/范围**: 18 章、223 地图、294 剧情场景、636 MGO、88 立绘、72 战场、227 战斗/法术组、12 RNG、12880 条消息

## 规范检查

- [x] 正式地图继续使用 `TileMapLayer + PalTileMapWorld`
- [x] CPU 渲染只用于诊断，不扩展生产能力
- [x] 选帧、坐标、层级与遮挡进入共享逻辑
- [x] 真实画面使用带窗口运行和实际截图验收
- [x] 私有资产、原版数据和 Key 不进入公开仓
- [x] 每个阶段独立提交并运行风险相称的回归

## 项目结构

```text
src/
├── presentation/      # 展示度量、资源解析、共享世界快照
├── world/             # PalTileMapWorld 与 PalHd2DWorld
├── audio/             # 原音频与独立 Voice 播放器
├── ui/                # 经典和高清 UI
└── battle/            # 经典结算与高清战场视图

tests/                 # 合成、真实资源和带窗口回归
tools/                 # 清单校验、资产台账与安全扫描
sword-assets/          # 被父仓忽略的嵌套 Private LFS 仓
```

## 每章完成定义

- 清单覆盖该章地图、人物/NPC、立绘表情、战场、敌人/法术、过场和 TTS。
- 缺失高清资源有显式回退，不出现导入错误或剧情中断。
- 从上一章结束状态自然进入下一章，关键物品、队伍、事件和存档保持正确。
- 运行该章主线回归、TileMap 正式路径回归、1080p 真实窗口截图、性能检查和语音听检。
- 代码仓与素材仓分别创建独立提交；通过门禁后为素材仓打章节 Tag。

## 冲突与取舍

- 现有 `docs/REMASTER.md` 把高清模式描述为 320×200 的整数放大壳。新规格要求真正 1080p 3D 视图；因此经典内容矩形只保留在兼容模式，高清世界使用完整 16:9 画布。
- AGENTS.md 要求正式地图以 TileMapLayer 为准。新 3D 世界是共享快照的视图适配器，不取代 TileMap 的地图载入、碰撞、脚本或验收。
- 当前未安装 Blender。阶段 0 使用 Godot 原生模块化几何、Sprite3D 和景物卡片，不把 Blender 设为首期依赖。
- 用户的 Tripo Studio 会员不包含开发者 API 额度。Tripo 只进入可选人工生产链：Bitto 参考图 → Studio 网页生成 → 手动导出 GLB → 本地验证/入仓；代码不读取 `TRIPO_API_KEY`。
