# 规格说明：非商业同人 HD-2D 高清重构与 TTS

**需求 ID**: `hd2d-remaster-tts`  
**目标分支**: `release`  
**目标平台**: PC 桌面，1920×1080、16:9、60 FPS

## 产品目标

本项目继续保留现有十八章剧情、事件脚本、地图拓扑、战斗、存档和玩家本地导入数据，以《逸剑风云决》式固定电影化镜头重建场景表现：真实 3D 地形与建筑、像素 Sprite3D 人物、水墨远景、实时灯光、阴影、雾效和景深，剧情立绘使用非像素传统国风手绘。

项目定位为永久免费、无广告、无赞助、非官方同人作品。公开代码仓不得包含原版提取资源、完整对白资产、私有高清素材、生成语音或任何 API Key；实际高清素材与 TTS 保存到本地嵌套的 Private 仓库 `sword-assets/`。

## 功能需求

### R1 地图和渲染

- `TileMapLayer + PalTileMapWorld` 继续承担正式地图载入、碰撞、事件坐标、脚本选帧和经典回归。
- 共享 `PalWorldTransform` 和 `PalWorldPresentationSnapshot` 将 PAL half-tile、角色/NPC 位置、方向、层级和场景状态转换为 3D 视图输入。
- `PalHd2DWorld` 只能消费共享快照和高清资源清单，不得实现第二套移动、碰撞、脚本或事件规则。
- 高清模式使用 1920×1080 全画布；320×200 只用于经典兼容和像素基准。
- 探索镜头固定，不允许玩家自由旋转；场景可在不可行走边界外增加纯视觉远景。

### R2 高清资源与 MOD

- 资源按逻辑 ID 解析，覆盖地图、场景人物、立绘、战场、战斗动作、过场和语音。
- 资源优先级为：启用的 MOD → `sword-assets/` 私有高清包 → 玩家本地经典导入 → 合成占位资源。
- 无效或缺失高清资源不得中断主线；只记录一次诊断并回退。
- v1 MOD 仅允许替换立绘、角色 Sprite、语音和 UI 主题，不执行脚本。
- 所有二进制资产使用 Git LFS；提示词、模型、协议、尺寸、来源、SHA-256 和审核状态保存在普通 Git 清单中。
- Tripo3D 仅作为可选的 Studio 网页 3D 工坊：用于独特建筑、道具、岩石等静态资产，人工导出 GLB 后进入 Private 素材仓；不接入单独计费的 Tripo API。

### R3 TTS

- 运行时严格使用 `ScriptVM.dialog_round_ready(PackedInt32Array)` 提供的消息 ID 序列查找语音。
- MiniMax 仅在开发期离线生成；客户端不包含 Key、不调用在线 TTS。
- 只朗读剧情对白和旁白，不朗读菜单、物品获得、系统提示或战斗数值。
- 默认手动推进；真正翻页、跳过、切场景、进战斗和读档必须停止旧语音。
- 可选自动模式仅在文字已经完整且语音自然结束后推进；缺失语音时退回手动。
- 主要角色使用独立系统声线，NPC 按年龄、性格和阵营分型；禁止模仿原作演员或使用未经授权的克隆声音。

### R4 章节交付

- 第一章先完成客栈室内、余杭/十里坡室外和代表性战斗三场景垂直切片。
- 第一章先生成三条代表样音并人工验收；未通过前不得批量生成后续章节。
- 后续逐章完成该章地图、人物、立绘、战场、战斗动作、过场、TTS、主线回归和带窗口截图。
- 第十三章桃源村支线必须作为独立门禁完成真实运行验证。

## 非功能要求

- 中画质最低目标 GTX 1060 / RX 580 级独显，1080p 正常探索和战斗稳定 60 FPS。
- 普通帧 p95 不高于 16.7ms；场景切换稳定后不得持续出现超过 33ms 的帧。
- `.env.local` 必须被忽略且权限为 `600`；任何报告、日志、提交、导出包都不得包含密钥。
- 经典 TileMap 回归、全部主线脚本和存档兼容性不得因高清路径发生语义变化。
- 每个边界清晰的基础设施、章节或 Bug 修复必须独立提交并运行对应回归。

## 发布边界

- `v0.1.5` 只作为旧版代码基线；含原版派生资源的旧 APK 不上传公开 Release。
- 免费分享和免责声明不等于授权。公开安装包前必须检查权利方规则、字体/音乐/音效、Bitto/MiniMax 条款、同人声明和下架联系方式。
- 未通过发布门禁时，高清资产、TTS 和完整构建只保存在 Private 素材仓与本地机器。

## 验收标准

- 阶段 0 合成测试覆盖展示度量、坐标转换、资源/MOD 优先级、清单校验和 TTS 播放生命周期。
- 第一章三张概念图和三条样音均有生成元数据、文件哈希和人工验收结论。
- 正式地图路径继续从 `PalTileMapWorld` 载入，并在真实 Godot 窗口检查高清画面。
- 代码仓敏感内容扫描确认没有 `sword-assets/`、`.env.local`、原版 Data、实际对白清单和音频。
